# bust-warp

Webカメラの映像で、胸の部分だけを膨らませて見せるブラウザアプリ。
姿勢推定で体に追従し、動きに合わせて上下左右に揺れる。陰影で立体感もつける。

**▶ https://miyumiyu.github.io/bust-warp/**

- 映像の処理はすべてブラウザの中で行い、映像がどこかへ送信されることはない
- インストール不要。ページを開いてカメラを許可するだけ

## 動作環境

- Chrome / Edge の最新版を推奨（WebGL2 が必要）
- Webカメラ
- 初回は MediaPipe の実行環境と姿勢推定モデル（約 20MB）を読み込む。2 回目以降はキャッシュされる

## ビデオ通話や配信で使う（OBS の仮想カメラ）

[OBS Studio](https://obsproject.com/) の「ブラウザ」ソースでこのアプリを動かし、OBS の仮想カメラから
Zoom・Discord・Teams などに出せる。

### 1. OBS にカメラの使用を許可する（初回だけ）

OBS のブラウザソースは、起動オプション `--enable-media-stream` がないとカメラを使えない。
デスクトップなどにある OBS のショートカットを右クリック →「プロパティ」→「リンク先」の末尾に追記する。

```
"C:\Program Files\obs-studio\bin\64bit\obs64.exe" --enable-media-stream
```

OBS を起動し直すと有効になる（毎回このショートカットから起動する）。

### 2. OBS 用の URL を作る

1. 普段のブラウザでこのページを開き、見た目を調整する
2. パネルの「カメラ・OBS 出力」で使うカメラを選ぶ（自動なら OBS Virtual Camera などの仮想カメラは避ける）
3. 「OBS 用 URL をコピー」を押す。今の設定とカメラが URL に入る

設定を変えたら、もう一度 URL をコピーして OBS 側を貼り替える。

### 3. OBS に追加して仮想カメラを開始する

1. ソースの「+」→「ブラウザ」を追加し、URL にコピーした URL を貼る
2. 幅・高さをカメラの解像度に合わせる（パネルに表示される値。通常は 1280 × 720）
3. OBS の「仮想カメラ開始」を押し、通話アプリのカメラに「OBS Virtual Camera」を選ぶ

### うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「OBS からカメラを使えません」と出る | 手順 1 のショートカットから OBS を起動しているか確認する |
| 「カメラを開けません」と出る | 同じ Webカメラを OBS の「映像キャプチャデバイス」など別の場所で使っていないか確認する（同時に使えないカメラが多い） |
| 動きが重い | OBS の「設定」→「詳細設定」→「ブラウザソースのハードウェアアクセラレーションを有効にする」が ON か確認する。URL を作る前に姿勢推定モデルを lite にする |
| 膨らみが斜めを向く | ブラウザソースを右クリック →「対話」を開き、正面を向いて F キーを押す |

「対話」の画面では、E（エフェクト）・J（揺れ）・L（陰影）などのキー操作も使える。

## 注意

## 開発

```sh
npm install        # WASM のコピーと姿勢推定モデルのダウンロードも行う
npm run dev        # http://localhost:5173 を開く
npm run build      # dist/ に公開用ファイルを出力
```

カメラの許可を求められたら許可する。`localhost` と HTTPS 以外ではブラウザがカメラを使わせないので注意。
`main` ブランチに push すると、GitHub Actions がビルドして GitHub Pages に公開する（`.github/workflows/deploy.yml`）。

## 操作

| キー | 動作 |
|---|---|
| E | エフェクトの ON/OFF（比較用） |
| L | 陰影の ON/OFF |
| J | 揺れの ON/OFF |
| Space | 揺らしてみる（バネに衝撃を与える） |
| F | 今の向きを正面として登録し直す |
| H | 手で触る の ON/OFF |
| S / C / M | 骨格 / 胸の推定位置 / メッシュ の表示 |
| T | マウスで操作テスト（人物がいなくてもマウス位置で変形と揺れを試せる。ドラッグするとマウスが手になって胸に触れる） |

設定はブラウザに保存される。「設定を初期値に戻す」で初期化できる。

## 仕組み

```
カメラ → 姿勢推定（MediaPipe Pose Landmarker、GPU）
       → 肩 2 点を One Euro Filter で平滑化 → 胸の位置を推定（肩幅基準、体の向きも補正）
       → バネ・ダンパで揺れを計算
       → 192×108 の格子メッシュを CPU で変形 → WebGL2 で映像テクスチャを貼って描画
       → 胸を高さ場とみなしてフラグメントシェーダで陰影をつける
```

### 大きさ・範囲・飛び出し

| 設定 | 意味 |
|---|---|
| 大きさ | 胸の部分を画面上で拡大する量 |
| 範囲 | 変形する楕円の大きさ（体に対する広がり） |
| 飛び出し | 胸が前に出る高さ。正面のカメラでは奥行きが直接見えないので、次の 3 つで表す |

- **陰影**: 高さから法線を求め、上からの光で拡散光・ツヤ・胸の下に落ちる影をつける。飛び出すほど濃くなる
- **遠近**: カメラに近いほど大きく写るので、飛び出し × 0.5 を大きさに足す
- **視差**: 体をひねると、前に出ている頂点ほど横にずれて見える（「体の向きを補正」が ON のとき）

飛び出しを 0 にすると陰影は消え、大きさだけの平面的な拡大になる。

### 手で触る

姿勢推定の手首・人差し指・小指の点から、手を円で近似する（手首から指先までを覆う）。

- **押す**: 見た目の胸と手の円が重なると、重なった分だけ手から離れる向きに胸を押す（揺れのバネへの外力）。離すと揺れながら戻る
- **引きずる**: 触れている間は、胸が手の動きに引っ張られる
- **潰れる**: 押されている胸は、大きさと飛び出しが最大 3 割減る
- **手は変形させない**: 手の円の中では変形を打ち消し、陰影もつけない（手が胸と一緒に膨らんだり揺れたりしない）。
  円の外へ向けて変形を滑らかに戻す幅は、手に向かって押し縮められる量から決め、メッシュが裏返らないようにしている

「揺れ」が OFF のときも、揺れないバネ（臨界減衰）で押し出しは効く。
奥行きは分からないので、手が胸の手前を横切るだけでも「触れた」と扱う。

### 服の着せ替え

服を単色で塗ったり、用意した柄に着せ替えたりできる（単色、ボーダー、ストライプ、ギンガムチェック、ドット、アーガイル、迷彩）。

「肌色プリセット」でライト・ピーチ・ベージュ・タン・ブラウン・ダークから選ぶと、単色モードと選んだ色が設定される。
服全体と膨らみ部分に同じ色が適用される。色はカラーピッカーで微調整でき、プリセットを選び直しても質感・明るさの設定は保持される。以前保存した無地モードも単色モードとして読み込まれる。

「服の質感・明るさ」でテクスチャを **なし・織り布・ニット** から選び、強さ（0〜1）・大きさ（0.4〜3）・明るさ（0.25〜2）を調整できる。
「陰影」の ON/OFF・陰影の強さ・光の向き・ツヤは単色モードにも反映される。完全な単色にする場合は、テクスチャを「なし」、陰影を OFF、明るさを 1 にする。
これらの設定はブラウザへの保存と OBS 用 URL にも含まれる。

- **服の領域**: MediaPipe の人物セグメンテーション（`selfie_multiclass_256x256`。背景・髪・肌・服などを区別する）で求め、服全体を塗り替える。
  モデル（約 16MB）は着せ替えを使うときだけ読み込む
- **単色**: 元映像の布目・しわ・縫い目・プリントの濃淡を引き継がず、選んだ色と新しい布目模様に、設定した明るさ・陰影・ツヤを適用する
- **柄モード**: 各画素の明るさを「服全体の平均の明るさ」との比にして柄の色に掛けるので、元の服の濃淡が残る
- **柄は体に固定**: 肩の中点・肩の軸・肩幅を基準にした座標で柄を描くので、体と一緒に動く。
  元の映像の座標で塗ってからメッシュを変形するので、柄は膨らみに沿って伸びる

|---|---|
| `src/main.ts` | カメラ・推定・描画のループ |
| `src/camera.ts` | カメラの一覧と選択（仮想カメラを避ける） |
| `src/clothing.ts` | 服の領域推定（セグメンテーション）と、服の平均の明るさの計測 |

| `src/chest.ts` | 肩から胸の位置・変形範囲を計算 |

| `src/renderer.ts` | WebGL2 描画（陰影と着せ替えのシェーダを含む） |

### メッシュ変形

胸 1 つにつき「放射状に押し広げる」「揺れで平行移動する」の 2 つの写像を用意し、順番に合成する。
重みは `(1 - t²)³`（t は楕円で正規化した距離）。各写像は単体で折り返しが起きない範囲にパラメータを制限している
（大きさ ≤ 1.0、揺れの移動量は揺れ領域の半径の 0.32 倍まで）。

ただし胸の間では圧縮が重なるので、揺れが最大になったときだけ格子の分解能が足りず三角形が裏返ることがある。
毎フレーム裏返りを検査し、見つかったらそのフレームは揺れを弱めて作り直す（約 0.7 秒かけて元に戻る）。

## 既知の制限

- 変形範囲に腕（前腕）や背景が入るとそれらも一緒に歪み、陰影もつく（手は除外している） → セグメンテーションで服の領域だけに限定する
- 黒い服は掛け算の陰影がほとんど効かず、ツヤでしか丸みが出ない（着せ替えで明るい色にすると陰影が見えるようになる）
- 着せ替えでは、下の服（ズボンなど）も「服」として同じ色・柄になる。服の境目は推定なので、縁が少しずれることがある
- 光の向きは手動の設定値で、カメラ映像から実際の照明方向を推定しない。単色モードは元映像の明暗も引き継がないため、部屋に合わせて明るさ・陰影を調整する
- 追加テクスチャは手続き的に描く織り布・ニットの模様で、人肌のテクスチャではない
- 胸の位置は肩からの推定なので、姿勢（前かがみなど）や体型によってずれる → 「肩からの距離」「左右の間隔」で調整する
- 体の向き（yaw）は MediaPipe が推定する左右の肩の奥行き（z）の差から求めている。この推定は偏りやすく、
  特に腰が映っていないと正面でも 20〜30° ずれる。そのため検出開始から約 1.5 秒の向きを「正面」として記録し、
  そこからの差だけを使う（±10° 以内は無視）。開始時に横を向いていた場合は F で登録し直す。
  HUD に推定した向きを表示している
